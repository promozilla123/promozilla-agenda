# Agenda do PromoZilla

Posts de conteúdo aprovados no artefato de aprovação. O robô (Cloudflare) lê o `agenda.json` a cada 15 minutos e publica cada post no dia e horário marcados (horário de Brasília): primeiro o feed (Instagram, Facebook, Threads) e, na rodada seguinte, os stories.

Não edite à mão: o Claude atualiza este repositório.
